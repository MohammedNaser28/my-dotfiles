Dots for a compositor that scrolls sideways.

Everything is stowed. Pick what you want.

Each app lives in its own stow package. Run stow.sh and every configured app gets symlinked into place.

// installation

Clone, install, stow, go

Requires an Arch-based distro with git and yay for the AUR packages. Each step is optional — grab only what you need.

01
Clone the repo

Recursive clone pulls the wallpaper submodule too.

git clone --recursive https://github.com/MohammedNaser28/my-dotfiles.git ~/.dotfiles-sevens
cd ~/.dotfiles-sevens
02
Install packages (optional)

Let the installer handle all the dependencies:

./install.sh --packages          # pacman packages only
./install.sh --packages --yay    # includes AUR packages

Or install manually — all the packages are listed in install.sh.

03
Stow the configs

Creates symlinks for every configured app. Stow is idempotent — run it any time.

./stow.sh
04
Reload niri

Applies the new config without a full session restart.

niri msg action reload-config
